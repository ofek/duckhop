# DuckHop

DuckHop is a DuckDB extension for persistent graph indexing and native traversal.

DuckHop is intended to make graph traversal available alongside ordinary relational queries. Reachability, dependency graph analysis, data lineage, authorization relationships, and network topology are representative uses. The repository currently provides a loadable DuckDB 2.x extension skeleton; graph functionality and a public query API are still to come.
